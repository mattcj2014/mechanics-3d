How placement works

  • Label: one click.
  • Length: click endpoint 1, then endpoint 2.
  • Vector: click the tail, then the arrow head.
  • Drag normally to rotate. A placement is only made on a click, not a drag.

One-time token setup
  1. Open GitHub → create a fine-grained token.
  2. Select the repository owner as resource owner and give it access to only this repository.
  3. Under Repository permissions, set Contents → Read and write. Choose an expiration and generate the token.
  4. Paste it here and click Connect. The token is cleared from this field and kept only in memory until you disconnect or close/reload the page.

Use the branch configured in Settings → Pages. Direct writes require a branch that permits your account to commit.
